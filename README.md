# Distância de edição: PD recursiva x PD iterativa

Trabalho da disciplina de Projeto e Análise de Algoritmos, tema 7.9 (busca de string mais similar via distância de edição).

Elene Firmeza Ohata - Mestrado em Ciência da Computação (IFCE)

Vídeo: https://youtu.be/WyEEjWuUCE8

## Arquivos

- `distancia_edicao.ipynb`: implementação, testes, experimentos, gráficos e discussão. O notebook está salvo com as saídas, de modo que os resultados podem ser consultados sem executá-lo novamente.
- `grafico_exp1.png`, `grafico_exp1_loglog.png`, `grafico_exp2.png`, `grafico_exp3.png`: gráficos gerados pelo notebook.
- `resultados_exp1.csv`, `resultados_exp2.csv`, `resultados_exp3.csv`: tempos e distâncias de cada execução.
- `requirements.txt`: bibliotecas necessárias, nas versões utilizadas na execução.

## Como executar

Requer Python 3 (testado com a versão 3.14). As dependências são instaladas com:

```
pip install -r requirements.txt
```
